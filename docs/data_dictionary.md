# SmartPay Reconciliation — Data Dictionary

**Version:** 1.0

---

## 1. Platform Transactions Contract (`platform_transactions.csv`)

| Column | Type | Nullable | Description | Example |
|---|---|---|---|---|
| `transaction_id` | String | No | Unique transaction identifier generated by the payment platform | `TXN-NORM-001` |
| `original_transaction_id` | String | Yes | Parent payment transaction ID for refunds; null for regular payments | `TXN-NORM-REF-P01` |
| `transaction_type` | Enum | No | `PAYMENT` or `REFUND` | `PAYMENT` |
| `amount` | Decimal String | No | Transaction amount (positive decimal string) | `1500.00` |
| `currency` | ISO-4217 | No | 3-letter currency code | `INR` |
| `transaction_timestamp` | ISO-8601 | No | Datetime when platform recorded the payment | `2026-10-01T10:00:00Z` |
| `status` | String | No | Gateway processing outcome (`SUCCESS`, `REFUNDED`, `FAILED`) | `SUCCESS` |
| `merchant_reference` | String | Yes | Merchant order ID or external identifier | `ORDER-1001` |

## 2. Bank Settlements Contract (`bank_settlements.csv`)

| Column | Type | Nullable | Description | Example |
|---|---|---|---|---|
| `bank_entry_id` | String | No | Unique statement line identifier from the bank | `BNK-NORM-001` |
| `transaction_reference` | String | No | Platform transaction reference passed through clearing network | `TXN-NORM-001` |
| `entry_type` | Enum | No | `CREDIT` (incoming funds) or `DEBIT`/`REFUND` (settlement outflows) | `CREDIT` |
| `amount` | Decimal String | No | Settled amount received by/debited from merchant account | `1500.00` |
| `currency` | ISO-4217 | No | 3-letter currency code | `INR` |
| `settlement_timestamp` | ISO-8601 | No | Datetime when funds were posted by the acquiring bank | `2026-10-03T11:30:00Z` |
| `batch_id` | String | Yes | Clearing batch ID assigned by the bank | `BATCH-OCT-01` |
| `description` | String | Yes | Raw narrative text from bank statement | `Settlement for TXN-NORM-001` |

## 3. Reconciliation Status Codes

| Code | Severity | Category | Description |
|---|---|---|---|
| `CONFIRMED_MATCH` | `INFO` | Matched | Platform transaction and bank entry match on reference, amount, currency, and settle within reporting period. |
| `SETTLED_NEXT_MONTH` | `LOW` | Timing | Transaction belonging to reporting month settles in the subsequent calendar month within look-ahead window. |
| `AGGREGATE_ROUNDING_DIFFERENCE` | `LOW` | Precision | Line items match 1:1, but aggregate summation yields small variance within configured tolerance. |
| `DUPLICATE_PLATFORM_RECORD` | `MEDIUM` | Duplicate | Repeated platform transaction ID; duplicate isolated to avoid double counting. |
| `DUPLICATE_BANK_RECORD` | `MEDIUM` | Duplicate | Repeated bank statement line or duplicate settlement credit for same reference. |
| `ORPHAN_REFUND` | `HIGH` | Discrepancy | Platform refund whose original transaction ID is missing or not found in platform payments. |
| `MISSING_SETTLEMENT` | `HIGH` | Discrepancy | Platform payment recorded in month has no settlement credit in search window. |
| `UNMATCHED_BANK_CREDIT` | `HIGH` | Discrepancy | Bank credit received with no corresponding platform transaction record. |
| `AMOUNT_MISMATCH` | `HIGH` | Discrepancy | Transaction references match, but settled amount differs beyond rounding tolerance. |
| `CURRENCY_MISMATCH` | `CRITICAL` | Discrepancy | Transaction references match, but platform currency does not match bank currency. |
| `POSSIBLE_MATCH_REQUIRES_REVIEW` | `HIGH` | Ambiguous | Multiple candidate bank matches exist for a single platform reference. |

## 4. Financial KPI Metrics

- **Platform Gross (`platform_gross`)**: Sum of all canonical successful platform payments in the reporting month.
- **Platform Refunds (`platform_refunds`)**: Sum of all canonical platform refunds in the reporting month.
- **Platform Net (`platform_net`)**: `platform_gross - platform_refunds`.
- **Bank Settled Gross (`bank_settled_gross`)**: Sum of canonical bank credits posted in the reporting period.
- **Bank Debits (`bank_debits`)**: Sum of canonical bank debit entries posted in the reporting period.
- **Bank Net (`bank_net`)**: `bank_settled_gross - bank_debits`.
- **Net Variance (`net_variance`)**: `platform_net - bank_net`. Segregated per currency.
- **Reconciliation Rate (`reconciliation_rate_pct`)**: `(confirmed_matched_canonical_payments / eligible_canonical_payments) * 100`.
